# Idle Planet

A browser-based idle game inspired by Cookie Clicker, developed as my A-Level Computer Science NEA project.

**Result:** 70/70 marks

---

![Idle Planet screenshot](https://raw.githubusercontent.com/GermanKerrMan/Idle-Planet/main/Screenshots/IdlePlanetScreenshot.png)

## Features

- Population and money systems
- Workers and resource generation
- XP and levelling
- Achievements
- Prestige system
- Meteor minigame
- Save/load functionality
- Multiple planets
- Sound effects
- Light and dark themes

---

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage

This project taught me how to:

- Break features into manageable tasks
